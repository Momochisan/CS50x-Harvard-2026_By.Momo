# 🎮 Week 04 - Mario less
โปรแกรมจะรับค่าความสูงจากผู้ใช้ แล้วพิมพ์พีระมิดด้านเดียวด้วยเครื่องหมาย `#` โดยจำนวนแถวเป็นไปตามความสูงที่กำหนด

This program takes a height as input and prints a single-sided pyramid using `#` symbols, with the number of rows determined by the specified height.
