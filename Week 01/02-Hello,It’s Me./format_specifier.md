# Format Specifier
รูปแบบพิเศษที่ใช้เครื่องหมาย **percent sign `(%)`** ตามด้วยตัวอักษรเพื่อบอกว่าฟังก์ชัน `printf()` ต้องการแสดงข้อมูลแบบไหน 
เช่น จำนวนเต็ม เลขทศนิยม หรือข้อความ

### ☠️ `printf()` จะรู้ได้ไงว่าต้องแสดงข้อมูลอะไร?

เวลาใช้ `printf()` สามารถแสดงข้อมูลได้หลายประเภท เช่น ข้อความ ตัวเลข หรือค่าที่เก็บอยู่ในตัวแปร

จำเป็นต้องใช้ **Format Specifier** เพื่อกำหนดรูปแบบการแสดงข้อมูลให้ตรงกับค่าที่ต้องการแสดงผล


🧪 **ตัวอย่าง**

```c
int age = 19;

printf("Age: %d", age);
```

🖨️ **ผลลัพธ์**

```
Age: 19
```

`%d` ใช้แสดงค่าจำนวนเต็ม โดยค่าที่นำมาแสดงในตัวอย่าง คือ **age** ซึ่งมีค่าเป็น **19**


## 🖇️ โครงสร้างของ Format Specifier
ในรูปแบบทั่วไป คือ `%character`

- `%` **(percent sign)** เป็นเครื่องหมายเริ่มต้น **Format Specifier**
- ตัวอักษรที่ตามหลัง คือ `%` จะกำหนดรูปแบบของข้อมูล

🧪 **ตัวอย่าง**

```
%d
```

  + `%` คือ **percent sign**
  + `d` คือ ตัวอักษรที่กำหนดความหมาย

- - -

### 1. `%d` หมายถึง **Integer**
แสดงข้อมูลประเภทจำนวนเต็ม **(int)**

🧪 **ตัวอย่าง**

```c
int age = 19;

printf("%d", age);
```


🖨️ **ผลลัพธ์**

```
19
```

🧪 **ตัวอย่าง (ใช้ร่วมกับข้อความได้)**

```c
printf("I am %d years old.", age);
```


🖨️ **ผลลัพธ์**

```
I am 19 years old.
```

- `%d` จะถูกแทนที่ด้วยค่าของตัวแปร **age**

- - -


### 2. `%f` หมายถึง Floating Point
แสดงข้อมูลประเภทเลขทศนิยม


🧪 **ตัวอย่าง**

```c
float height = 158.5f;

printf("%f", height);
```


🖨️ **ผลลัพธ์**

```
158.500000
```

- `%f` จะแสดงตัวเลข หลังจุดทศนิยม 6 ตำแหน่งเป็นค่าเริ่มต้น


🧪 **ตัวอย่าง (กำหนดจำนวนตำแหน่งที่ต้องการแสดงได้)**

```c
printf("%.2f", height);
```


🖨️ **ผลลัพธ์**

```
158.50
```

- `.2` หมายถึง ต้องการแสดงตัวเลขหลังจุดทศนิยม 2 ตำแหน่ง

- - -


### 3. `%s` หมายถึง String
แสดงข้อมูลประเภทข้อความ


🧪 **ตัวอย่าง**

```c
#include <cs50.h>
#include <stdio.h>

int main(void)
{
    string name = "Momo";

    printf("%s", name);
}
```


🖨️ **ผลลัพธ์**

```
Momo
```

🧪 **ตัวอย่าง (ใช้ร่วมกับข้อความอื่นได้)**

```c
printf("Hello, %s!", name);
```


🖨️ **ผลลัพธ์**

```
Hello, Momo!
```

- `%s` ถูกแทนที่ด้วยข้อความที่อยู่ในตัวแปร **name**

- - -


### 4. `%c` หมายถึง Character
แสดงข้อมูลประเภทอักขระ 1 ตัว **(char)**


🧪 **ตัวอย่าง**

```c
char grade = 'A';

printf("%c", grade);
```


🖨️ **ผลลัพธ์**

```
A
```
- `%c` แสดงค่าอักขระจากตัวแปรประเภท **char**

- - -


### 5. `%i` หมายถึง Integer
แสดงข้อมูลประเภทจำนวนเต็ม เช่นเดียวกับ `%d` เมื่อใช้งานกับ `printf()`


🧪 **ตัวอย่าง**

```c
int number = 100;

printf("%i", number);
```


🖨️ **ผลลัพธ์**

```
100
```

- การแสดงค่า **int** ทั่วไป สามารถใช้ `%d` หรือ `%i` ได้ทั้งคู่

- - -

### 🍱 กรณี Format Specifier หลายตัว
สามารถใช้ **Format Specifier** หลายตัวใน `printf()` ได้


🧪 **ตัวอย่าง**

```c
#include <cs50.h>
#include <stdio.h>

int main(void)
{
    string name = "Momo";
    int age = 19;

    printf("My name is %s and I am %d years old.", name, age);
}
```

🖨️ **ผลลัพธ์**

```
My name is Momo and I am 19 years old.
```

- - -

### ⚠️ ข้อสังเกตที่สำคัญ

- `%d` และ `%i` ใช้แสดงจำนวนเต็ม
- `%f` แสดงเลขทศนิยม ค่าเริ่มต้นจะแสดง 6 ตำแหน่ง หลังจุดทศนิยม
- `%s` ใช้แสดงข้อความ
- `%c` ใช้แสดงอักขระ 1 ตัว
- ถ้าใช้ **Format Specifier** หลายตัว ค่าที่ส่งเข้า `printf()` ต้องเรียงลำดับให้ตรงกัน
- **Format Specifier** ต้องตรงกับชนิดข้อมูลที่ส่งเข้าไป ไม่งั้นอาจเกิดปรากฎการ ที่ไม่สามารถกำหนดมาตรฐานภาษา **C (undefined behavior)**
