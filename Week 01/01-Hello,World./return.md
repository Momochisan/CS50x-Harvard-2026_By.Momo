# `return 0;`
เป็นคำสั่งสำหรับ **ส่งค่ากลับ (return)** จากฟังก์ชัน `main` และใช้บอกสถานะการสิ้นสุดของโปรแกรม


### 🤔 ทำไมจำเป็นต้องมีละ?
เพราะ `main` ถูกประกาศเป็น

```c

int main(void)

```
`int` หมายถึง ฟังก์ชัน **main** จะต้องคืนค่าเป็น **จำนวนเต็ม (integer)**

ดังนั้น `return 0;` จึงเป็นการส่งค่าจำนวนเต็ม `0` กลับไปเมื่อโปรแกรมทำงานเสร็จสิ้น

- `return` คือ คำสั่งสำหรับการส่งค่ากลับจากฟังก์ชัน และจบการทำงานของฟังก์ชัน
- `0` คือ ค่าที่ส่งกลับ ใช้บอกว่าโปรแกรมนี้ทำงาน**สำเร็จ (success)**
- `;` คือ เครื่องหมาย**เซมิโคลอน (Semicolon)** จบคำสั่ง

**สรุปง่ายๆ** คือ โปรแกรมทำงานเสร็จแล้ว และส่งสถานะว่าสำเร็จกลับไป

- - -

### 🧠  0 ส่งกลับไปไหนอะ?
คำสั่ง `main` จะจบการทำงานในค่า `0` ที่ถูกใช้เป็น **exit status** ของโปรแกรม เช่น

- ค่า `0` คือ **success** โปรแกรมทำงานสำเร็จ
- ค่าที่ไม่ใช่ `0` คือ มักจะใช้บอก **Error** หรือ **Other Status** หรือสถานะอื่น

ค่าพวกนี้สามารถนำไปใช้กับระบบที่เรียกโปรแกรมได้ เช่น **operating system** หรือ **shell**

- - -

### 📜 ความหมายของ `return 0;`

| คำ | คำอ่าน | ความหมาย |
|------|-------|-------|
| `return` | รีเทิร์น | ส่งค่ากลับจากฟังก์ชัน |
| `0` | ซีโร่ | ค่าที่ใช้บอกการทำงานสำเร็จ |
| `;` | เซมิโคลอน | เครื่องหมายจบคำสั่ง |

### ⚠️ ข้อสังเกตที่สำคัญ
- `return` ทำให้ฟังก์ชัน หยุดทำงานและส่งค่ากลับ
- `return 0;` ใน **main** ใช้คืนค่า `0` เพื่อบอกว่าการทำงานของโปรแกรมสำเร็จ
- ค่า `return` ต้องสอดคล้องกับ `return type` ของฟังก์ชัน
  + เพราะ `main` ที่ต้องใช้ `int` จะคืนค่าเป็นจำนวนเต็ม เช่น **0, 1, 2** ได้
- `return 0;` จะอยู่ท้าย **main** บ่อย เพราะเป็นจุดที่โปรแกรมทำงานเสร็จสมบูรณ์
