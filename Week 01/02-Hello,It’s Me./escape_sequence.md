# Escape Sequence
รูปแบบพิเศษที่ใช้เครื่องหมาย **backslash (`\`)** ตามด้วยตัวอักษร เพื่อแทนคำสั่งหรืออักขระบางอย่างภายใน **string** เช่น การขึ้นบรรทัดใหม่ การเว้นระยะ หรือการแสดงเครื่องหมายพิเศษ

### 🤔 ทำไมต้องใช้ Escape Sequence ?
บางอักขระ ไม่สามารถเขียนลงใน **string** ได้ หรือเราต้องการให้ข้อความแสดงผลในรูปแบบที่กำหนด เช่น การขึ้นบรรทัดใหม่

จึงต้องใช้ **Escape Sequence** เพื่อบอกโปรแกรมว่า ต้องการให้แสดงผลหรือจัดรูปแบบข้อความอย่างไร

🧪 **ตัวอย่าง**

```python

printf("Hello\nWorld");
```

🖨️ **ผลลัพธ์**

```
Hello
World
```

- `\n` ไม่ได้หมายถึงการแสดงตัวอักษร ส่วน `\` และ `n` ที่ออกมาบนหน้าจอ
- แต่เป็นคำสั่งให้ **ขึ้นบรรทัดใหม่**



## 🖇️ โครงสร้างของ Escape Sequence
โดยปกติแล้ว ประกอบด้วย `\` และ อักขระ

- `\` **(backslash)** เป็นตัวบอกว่า อักขระตามหลังเป็น **Escape Sequence**
- ตัวอักษรด้านหลัง `\` กำหนดว่า ต้องการให้โปรแกรมทำอะไร

🧪 **ตัวอย่าง**

```
\n
```

  + `\` คือ **backslash**
  + `n` คือ ตัวอักษรที่กำหนดความหมาย

- - -

### 1. `\n` หมายถึง **New Line**
สำหรับการขึ้นบรรทัดใหม่

🧪 **ตัวอย่าง**

```c

printf("Hello\nWorld");
```

🖨️ **ผลลัพธ์**

```
Hello
World
```

- หลังจากโปรแกรมแสดง **Hello**
- แล้ว ฝั่ง `\n` จะทำให้ตำแหน่งการแสดงผล เลื่อนไปยัง บรรทัดถัดไป


- - -


### 2. `\t` หมายถึง **Horizontal Tab**
สำหรับการเว้นระยะในแนวนอนหรือ **Tab**

🧪 **ตัวอย่าง**

```c
printf("Name:\tMomo");
```

🖥️ **ผลลัพธ์**

```
Name:   Momo
```

`\t` เหมาะในการจัดระยะข้อความให้มีช่องว่าง ในลักษณะของ **Tab**

- - -


### 3. `\"` หมายถึง Double Quote
สำหรับแสดงเครื่องหมาย **Double Quote (")** ภายใน **string**
ส่วน `"` ตรงนี้ปกติแล้ว จะใช้เป็นจุดเริ่มต้นและสิ้นสุด


🧪 **ตัวอย่าง**

```c
printf("He said \"Hello\"");
```

🖥️ **ผลลัพธ์**

```
He said "Hello"
```

- - -


### 4. `\\` หมายถึง Backslash
สำหรับเครื่องหมาย **Backslash (\)** ให้กลายเป็นตัวอักษร เพราะว่า `\` ใช้เป็นตัวเริ่มต้น **Escape Sequence** อยู่แล้ว จึงต้องใช้  `\\`  ถ้าต้องการแสดง **backslash**


🧪 **ตัวอย่าง**

```c
printf("C:\\Users\\Momo");
```

🖥️ **ผลลัพธ์**

```
C:\Users\Momo
```

- - -


### 5. `\'` หมายถึง Single Quote
สำหรับแสดงเครื่องหมาย  **Single Quote (')**


🧪 **ตัวอย่าง**

```c
printf("It's Momo");
```
กรณีนี้สามารถเขียน `'` ได้โดยตรง เพราะ **string** ภาษา C ใช้ `"` เป็นตัวครอบข้อความ แต่ `\'` สามารถใช้เพื่อแทน **single quote** ได้เช่นกัน


```c
printf("It\'s Momo");
```


🖥️ **ผลลัพธ์**

```
It's Momo
```

- - -

### ⚠️ ข้อสังเกตที่สำคัญ
- **Escape Sequence** มักเริ่มต้นด้วย `\` **(backslash)**
- `\n` ไม่ได้หมายถึงตัวอักษร **n** แต่หมายถึง **New Line**
- `\t` สำหรับ **Tab**
- `\"` เมื่อเราต้องการใส่ `"` ภายใน **string**
- `\\` ใช้ตอนเราต้องการแสดง `\` 
- **Escape Sequence** ใช้ควบคุมหรือแสดงอักขระพิเศษใน **string**
