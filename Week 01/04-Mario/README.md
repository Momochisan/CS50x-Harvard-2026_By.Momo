# 🎮 Week 04 Mario
โปรแกรมนี้รับค่าความสูงจากผู้ใช้ แล้วสร้างพีระมิดด้วยเครื่องหมาย `#` ตามรูปแบบที่กำหนด โดยแบ่งเป็น **Mario-less** เป็นพีระมิดด้านเดียวและ **Mario-more** เป็นพีระมิดสองด้าน


This program takes a height as input and prints pyramids using # symbols. It includes Mario-less, which creates a single-sided pyramid, and Mario-more, which creates a double-sided pyramid.
