# `string name = get_string()`
เป็นคำสั่งที่ใช้ รับข้อความจากผู้ใช้ แล้วนำข้อความที่ได้รับมาเก็บไว้ในตัวแปร **name**

### 🖇️ โครงสร้างของ `string name = get_string()`

### 1. `string`
หมายถึง **ชนิดข้อมูล (data type)** สำหรับเก็บข้อมูลประเภทข้อความ

- `string` คือ ชนิดข้อมูลที่ใช้เก็บข้อความ
- ใน **CS50** `string` มาจาก **CS50 Library**
- จึงต้องมี `#include <cs50.h>` ก่อนจึงจะสามารถใช้ `string` ได้

🧪 **ตัวอย่าง**

```c
#include <cs50.h>

string name;
string nickname;
string color;

```
