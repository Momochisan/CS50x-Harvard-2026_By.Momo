# `string name = get_string()`
เป็นคำสั่งที่ใช้ รับข้อความจากผู้ใช้ แล้วนำข้อความที่ได้รับมาเก็บไว้ในตัวแปร **name**

### 🖇️ โครงสร้างของ `string name = get_string()`

### 1. `string`
หมายถึง **ชนิดข้อมูล (data type)** สำหรับเก็บข้อมูลประเภทข้อความ

- `string` คือ ชนิดข้อมูลที่ใช้เก็บข้อความ
- ใน **CS50** `string` มาจาก **CS50 Library**
- จึงต้องมี `#include <cs50.h>` ก่อนจึงจะสามารถใช้ `string` ได้

🧪 **ตัวอย่าง**

```c
#include <cs50.h>

string name;
string nickname;
string color;

```

- - - 

### 2. `name`
หมายถึง **ชื่อตัวแปร (variable name)** ที่ใช้บอกข้อมูลที่เราต้องการเก็บ

- สามารถเปลี่ยนชื่ออื่นๆได้ตามต้องการ

🧪 **ตัวอย่าง**

```c

string nickname = get_string("What's your nickname? ");

```
ตรงนี้ `nickname` คือ ชื่อตัวแปร ที่เราตั้งขึ้นเองและสามารถเปลี่ยนเป็นชื่ออื่นได้ เช่น `name`, `username` หรือ `my_name` โดยไม่ทำให้การทำงานของ `get_string()` เปลี่ยนไป

- - -

### 3. `=`
หมายถึง `การกำหนดค่า (assignment)` ให้กับตัวแปร

- `=` ใช้กำหนดค่าที่อยู่ด้านขวาให้กับตัวแปรด้านซ้าย
- **ด้านซ้าย** คือ ตัวแปรที่ต้อง การเก็บค่า
- **ด้านขวา** คือ ค่าที่ต้อง การนำมาเก็บ


🧪 **ตัวอย่าง**

```c

string name = "Momo";

```

🖨️ **ผลลัพธ์**

```
name → "Momo"
```

ตัวแปร `name` มีค่าเป็น `"Momo"`


หรืออีกตัวอย่างนึง ถ้าค่ามาจาก  `get_string(): `

```c

string name = get_string(...);

```

ค่าที่ `get_string()` ส่งกลับ คือ จะเอามาเก็บไว้ในตัวแปร `name`


### 4. `get_string()`
หมายถึง ฟังก์ชัน **CS50 Library** ใช้สำหรับการรับข้อมูลประเภทข้อความจากผู้ใช้

- ถ้าใช้ฟังก์ชันนี้โปรแกรมจะรอให้ผู้ใช้ป้อนข้อความ แล้วฟังก์ชันจะส่งข้อความนั้นกลับมา

🧪 **ตัวอย่าง**

```c

get_string("What's your name? ");

```

🖥️ **เมื่อโปรแกรมทำงาน (ภาพจำลอง)**

```
What's your name?

User : Momo

What's your name? Momo
```
