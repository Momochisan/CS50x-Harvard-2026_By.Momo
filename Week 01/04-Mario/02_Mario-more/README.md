# 🎮 Week 04 - Mario more
โปรแกรมนี้จะรับค่าความสูงจากผู้ใช้ พิมพ์พีระมิดสองด้านด้วยเครื่องหมาย `#` โดยมีช่องว่างสองช่องคั่นระหว่างพีระมิดทั้งสองฝั่ง

This program takes a height as input and prints a double-sided pyramid using # symbols, with two spaces separating the two sides.
