# Escape Sequence
รูปแบบพิเศษที่ใช้เครื่องหมาย **backslash (`\`)** ตามด้วยตัวอักษร เพื่อแทนคำสั่งหรืออักขระบางอย่างภายใน **string** เช่น การขึ้นบรรทัดใหม่ การเว้นระยะ หรือการแสดงเครื่องหมายพิเศษ

### 🤔 ทำไมต้องใช้ Escape Sequence ?
บางอักขระ ไม่สามารถเขียนลงใน **string** ได้ หรือเราต้องการให้ข้อความแสดงผลในรูปแบบที่กำหนด เช่น การขึ้นบรรทัดใหม่

จึงต้องใช้ **Escape Sequence** เพื่อบอกโปรแกรมว่า ต้องการให้แสดงผลหรือจัดรูปแบบข้อความอย่างไร

🧪 **ตัวอย่าง**

```python

printf("Hello\nWorld");
```

🖨️ **ผลลัพธ์**

```
Hello
World
```

- `\n` ไม่ได้หมายถึงการแสดงตัวอักษร ส่วน `\` และ `n` ที่ออกมาบนหน้าจอ
- แต่เป็นคำสั่งให้ **ขึ้นบรรทัดใหม่**



## 🖇️ โครงสร้างของ Escape Sequence
โดยปกติแล้ว ประกอบด้วย `\` และ อักขระ

- `\` **(backslash)** เป็นตัวบอกว่า อักขระตามหลังเป็น **Escape Sequence**
- ตัวอักษรด้านหลัง `\` กำหนดว่า ต้องการให้โปรแกรมทำอะไร

🧪 **ตัวอย่าง**

```
\n
```

  + `\` คือ **backslash**
  + `n` คือ ตัวอักษรที่กำหนดความหมาย
